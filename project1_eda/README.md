# Netflix Movies and TV Shows EDA
## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset.
The objective of this analysis is to explore:
- Netflix content trends
- Movies vs TV Shows distribution
- Release year patterns
- Country-wise content production
- Ratings distribution
- Content growth over time

The project was built using:
- Python
- Pandas
- Matplotlib
- Seaborn
- Kaggle Notebook

---

# Dataset

Dataset Source:
https://www.kaggle.com/datasets/shivamb/netflix-shows

The dataset contains information about Netflix titles, including:
- Type (Movie/TV Show)
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre

---

# Business Insights

- Movies dominate Netflix content compared to TV Shows.
- Netflix content additions increased rapidly after 2015.
- The United States contributes the highest amount of content.

---

# Key Findings

1. Movies are significantly more common than TV Shows.
2. TV-MA is the most frequent content rating.
3. Netflix content growth accelerated after 2015.
4. Several categorical columns contain missing values.
5. The dataset contains a few outliers in release years and duration.
